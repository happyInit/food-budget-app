> **데이터 소스 타당성 검증 · 작성 2026-07-12.** 실제 라이브 점검 + 샘플 추출 결과.

## 1. 한 줄 결론

**오아시스는 크롤링 기술적으로 충분히 가능하다.** anti-bot 없음 + 서버사이드 렌더링(SPA 아님) + 4단 가격 + 소비기한·핫딜 타이머까지 HTML에 존재. 마켓컬리보다 오히려 수월.

---

## 2. 접근성 점검 (라이브 확인)

| 항목 | 결과 |
|---|---|
| **anti-bot** | ❌ 없음. 서버 `mod_myfixip`(네이버클라우드 LB) — **Cloudflare/Akamai 아님**, 챌린지·캡차 없음 |
| **robots.txt** | 404 (파일 없음 = robots 차단 규칙 없음) |
| **렌더링** | **서버사이드 HTML** — 상품 링크·가격·상품명이 응답 HTML에 그대로 존재 (JS 렌더 대기 불필요) |
| **CORS** | `Access-Control-Allow-Origin: *` (커스텀 헤더 다수 → 내부 JSON API 존재 추정) |

---

## 3. 엔드포인트

| 용도 | URL | 비고 |
|---|---|---|
| 상품 상세 | `/product/detail/{id}` | `{id}` = `{categoryId}` 또는 `{categoryId}-{productId}` |
| **핫딜(마감세일)** | `/product/closeSale` | 상품 링크 리스트(검증 시 39개). **타임딜 성격** |
| 검색 | `/product/search?keyword={URL인코딩}` | 일반 식자재 수집용 |
| 브랜드관 | `/product/brandStore?brandCategoryId={id}` | 참고 |

> ⚠️ **핫딜 URL 정정**: 이전에 언급한 `?specialGroup=TIME_SALE`은 확인 안 됨. 실제 핫딜은 **`/product/closeSale`**. 타임/한정 세일 별도 그룹은 추가 탐색 필요.

## 4. 상품 상세 필드 위치 가이드 ⭐ (크롤러 파싱용)

### 상품명
```
<meta property="og:title" content="여기">
```

### 가격 — 반드시 메인 컨테이너 `<div class="price">` 안에서만 추출
```html
<div class="price">
  <div class="info_deal" data-end-time="1783868399000"> ← 타임딜 마감(epoch ms), 있을 때만
  <del class="normal dr40">5,430원</del>              ← 정상가
  <strong class="per dr40">40%</strong>               ← 할인율
  <b>3,230</b>원                                       ← 판매가
  <span class="discountCoupon_price">2,584</span> 원   ← 쿠폰 최대혜택가
</div>
```

> 🚨 **함정**: 페이지에 `info_price` 클래스 블록이 24개(추천/배너 카드)라, **`info_price`를 잡으면 엉뚱한 배너 가격(전 상품 동일 50%)**이 나옴. 반드시 **`<div class="price">` 메인 컨테이너**만 파싱할 것.

### 소비기한 · 원산지 · 중량
- **HTML에 존재함**(`소비기한`, `보관방법`, `원산지` 텍스트 확인) — 상품정보제공고시 테이블(`<th>/<td>` 구조)
- ⚠️ 빠른 정규식으론 미추출 → **테이블 파서 보강 필요**(다음 작업)

### 단위가격
- `100g당 400원` 형태로 HTML에 존재 → 파서 추가 가능

## 6. 제약 (하드 · 크롤러에게 전달)

- **교육용·비상업·비공개 전제**로만 (상업 서비스 아님).
- **anti-bot 우회(헤드리스 위장·캡차 우회) 금지** — 전제한 계획이면 안 함.
- robots 없음 ≠ 허용. ToS는 회색지대 → **요청 간격 넉넉히**(rate limit), 서버 부담 X.
- 개인정보·리뷰 수집 X. **가격·상품 메타만.**
