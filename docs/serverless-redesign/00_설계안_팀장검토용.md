## 1. 🔴 결정 요청

### D-1. 데이터 레지던시 — "두 클라우드 모두 서울"이 현재 사실이 아님 (답변 기한: **8/9 일요일**)

배경: 채택한 Bedrock 모델 2종(nova-micro·claude-3.5-sonnet v2)은 서울 리전 단독 호출이 **불가**하고, 크로스리전 프로파일로 도쿄·서울·싱가포르·시드니·뭄바이 5개 리전에 라우팅됩니다(CLI 실측 2026-08-07). 발표 예상질문에서 GLM-4.7 을 "도쿄 리전이라 배제"했는데 **채택 모델이 도쿄로 갈 수 있어 자기모순**입니다. VPC 프라이빗 엔드포인트를 써도 리전 간 라우팅은 그대로라 해결책이 아닙니다.

| 안 | 내용 | 비용 | 일정 | 되돌리기 | 재실측 |
|---|---|---|---|---|---|
| **A. 원칙 정정** | "APAC 역내 처리"로 재정의, 구성 불변 | 0 | 즉시 | 낮음 | 불필요 |
| B. 모델 교체 | 서울 단독 지원 모델로(요약→sonnet-20240620, 감정→haiku. **nova 대체재 없음**) | 단가 상승 방향 [미확인] | 재실측 필수 — 8/18 까지 빠듯 | 중간 | 필수 |
| C. Gemini 워크로드 GCP 이전 | 영수증·영상을 Cloud Run(서울)으로 — NAT 비용 소멸 | GCP 크레딧 [미확인] | 설계 재작성 + 학습 비용 | 높음 | 가용성 검증 필수 [미확인] |

### D-2. 챗봇·NER·가격탐지 3종의 처리 (답변 기한: 8/9)

배경: 실사 결과 문서와 실물이 다릅니다 — 챗봇은 라이브에서 LLM 호출이 0(템플릿 응답), NER 은 동기 API 가 아니라 저빈도 배치 백필 전용, 가격 탐지는 Kafka 발행→상시 컨슈머 체인이 실가동 중입니다.

**권고: 잔류 1종(챗봇) + 배치 부분 이전 2종(NER·가격 탐지).**
- **챗봇 잔류**: 이전해도 서버리스 AI 실증 기여가 없습니다(LLM 호출 0).
- **NER 은 배치 한정 이전**: "배치 전용"은 부적합 사유가 아니라 **적합 사유**입니다 — 저빈도 배치는 서버리스 최적 케이스(미호출 시 비용 0)이고, 틀린 것은 원 계획의 "동기 저지연 최대 난관" 전제였습니다. 단 **모델 파일이 현재 배포 이미지에 없어 아티팩트 확보가 선행 조건**입니다.
- **가격 탐지는 탐지 배치만 이전, 경계는 "Kafka 발행까지"**: 발행 이후 컨슈머 체인은 온프렘 잔존이므로 경로 절단이 없습니다.
- 두 종 모두 LLM 미사용이라 D-1(레지던시)과 무관하게 진행 가능합니다.

부수 결정 1건: 추천 랭킹 서빙은 호출 0 인데 상시 리소스를 점유 중 — **정지 여부를 함께 결정해 주십시오**(재기동 가능, 되돌리기 쉬움).

### D-6. AI 서버리스 이전과 EKS 이관의 순서 (답변 기한: **8/9** — 이 답에 따라 D-3 이 무의미해질 수 있습니다)

배경: 시방서 §11 은 온프렘 전체를 EKS 로 이관하며 CNPG PostgreSQL 을 🟢무수정으로 이식하는 것으로 되어 있습니다. 이 이관이 선행되면 서버리스 함수가 같은 VPC 안의 DB 에 접근하므로 **D-3 의 NAT·Tunnel 쟁점 자체가 소멸**합니다. 현재 설계는 "AI 서버리스가 먼저, DB 는 온프렘 잔존"을 암묵적으로 전제하고 있으나 **이는 확인된 바 없습니다.**

|---|---|---|
| 가. EKS 이관 선행 후 AI 서버리스 | D-3 불필요 | 단 EKS 일정에 종속 |
| 나. 동시 진행 | 경계 이동 중이라 조율 부담 최대 | — |
| 다. AI 서버리스 선행 (현 설계 전제) | D-3·Tunnel 검증이 임계 경로 | — |

### D-3. VPC·NAT 상시 고정비를 감수할 것인가 (답변 기한: 8/9 — IaC 착수 전)

배경: 이전 대상이 배치 4 + 온디맨드 API 2 인데, 함수를 VPC 안에 두면 NAT 게이트웨이 고정비가 **트래픽 0 이어도 월 730시간 전액** 과금됩니다. 하한 추정만으로 현재 월 비용의 **10배 이상**입니다(§5). 프라이빗 엔드포인트의 보안 명분도 D-1 배경(리전 간 라우팅 불변)으로 약해졌습니다.

**권고: 전 함수 VPC 밖 배치(고정비 0).** 포기하는 것은 "인터넷 미경유" 구성 하나이며(통신은 TLS), 이 포기를 명시 승인해 주시면 됩니다. 반대로 "인터넷 미경유"가 요구사항이면 월 ₩55,000+(하한)의 고정비 수용을 결정문에 남깁니다.

**이 권고가 성립하는 조건** — 전 함수 VPC 밖 = 고정비 0 은 **온프렘 PostgreSQL 접근을 이미 가동 중인 Cloudflare Tunnel 로 해결할 수 있을 때만 성립**합니다. 이전 대상 6종 전부가 DB 읽기·쓰기를 하고(가격 탐지는 온프렘 Kafka 발행까지 필요), 감정 분류는 실서비스 14만 건 경로입니다.

**미검증 항목** (착수 전 확인 필요)
- Cloudflare Tunnel 의 PostgreSQL TCP 경로 구성 가능 여부
- Lambda(VPC 밖)에서 그 경로를 사용하는 방식
- 배치 대량 처리 시 처리량·지연이 감당되는지

**조건 불성립 시 대안과 영향**

| 대안 | 고정비 | 일정 영향 |
|---|---|---|
| VPN / DX | 발생 | 리드타임으로 8/18 내 불가 개연 |
| NAT 게이트웨이 | 월 고정비 부활 (D-3 근거 소멸) | 없음 |
| DB 퍼블릭 노출 | 0 | 보안 승인 필요 — 권고하지 않음 |

**검증 시한: 월요일(8/10) 착수 전.** 이 검증이 실패하면 D-3 승인은 무효가 되며 재결정이 필요합니다. **D-6 의 답이 '가'(EKS 이관 선행)이면 이 결정 자체가 불필요해집니다.**

### D-4. 발표 논거 정정 승인 (문구 확정 8/15, 리허설 전 반영)

배경: 발표 자료의 "영상은 Bedrock 에 입력 자체가 없다(기술적으로 불가능)"는 **현재 기준 사실이 아닙니다** — 서울 리전에 영상 이해 모델(TwelveLabs Pegasus)이 온디맨드로 존재합니다(CLI 실측 2026-08-07). 함께 정정할 것: "두 클라우드 모두 서울"(D-1), GLM-4.7 배제 논거(도쿄 사유 → 다른 축으로 재작성).

**권고: 3개 문구 전부 정정.** 질문 한 개로 발표 전체의 신뢰가 무너지는 지점들입니다.

### D-5. IAM ReadOnlyAccess 부여 요청 (답변 기한: 8/8 인계 직후)

배경: 현 IAM 사용자는 조회 권한이 전무해 쿼터·비용·리소스 확인이 전부 AccessDenied 입니다(2026-08-07 실측 — Lambda·Service Quotas·Cost Explorer·EC2·Pricing 조회 전부 거부). 이 상태로는 **§5 비용의 [미확인] 항목(서울 실단가·크레딧 잔액·계정 적용 쿼터)이 해소되지 않으며**, 8/13 측정 목표치도 계정 실값 없이 추정으로 잡아야 합니다.

**권고: `ReadOnlyAccess` 부여**(최소로는 Billing·Service Quotas·Lambda 읽기). 부여 즉시 CLI 로 일괄 확인해 §5 를 실값으로 갱신합니다.

## 4. 아키텍처 요약

**실행환경** — 배치 4종은 콜드스타트가 쟁점이 아니고, 동기 2종만 접수 응답에서 쟁점입니다.

| 대상 | 배정 | 비고 |
|---|---|---|
| 배치 4종 (요약·감정·NER·가격 탐지) | Lambda(zip, x86_64) | NER 은 CRF 모델(343KB) 동봉 — 아티팩트 확보 선행. 가격 탐지는 온프렘 Kafka 발행 경로 필요(D-3 과 같은 검증 축) |
| 영수증·영상 | A안: Lambda(zip 우선, 초과 시 컨테이너) / C안: Cloud Run 서울 | 영상 120s < Lambda 15분 → **계획의 Fargate 행은 삭제**(전제 소멸) |

**이벤트 배선** — 계획의 S3 이벤트 전제는 무효(원본 미저장). 실물 계약을 유지합니다.

| 경로 | 설계 |
|---|---|
| 배치 4종 | Scheduler(UTC 정본, KST 주석) → Lambda 단발. 대량 백필만 분산 오케스트레이션(요약 6,873건은 ID 배열 직입 가능, 감정 14만 건만 S3 목록 필요). 가격 탐지는 발행까지 수행 후 종료(컨슈머는 온프렘), NER 은 저빈도 스케줄/수동 실행 |
| 동기 2종 | 프론트 계약(202+폴링) 유지, 내부만 접수/처리 Lambda 분리 + SQS·DLQ. 폴링 상태·30일 캐시·중복 방지 락 = 현행 Redis → **DynamoDB TTL 테이블 1개로 통합** |
| 공통 | 배치 완주 하트비트 + 미수신 알람(스케줄 미기동 감지). 시간대 혼재(KST 크론/UTC 프로세스)는 UTC 정본화로 해소 |

**IAM 경계** — 함수당 역할 1개(`mp-ai-{용도}-role`), 와일드카드 리소스 금지. Bedrock 은 **프로파일 ARN + 5개 리전 모델 ARN 동시 허용**이 필수(모델 ARN 단독 한정은 그대로 AccessDenied — 실측 확정). 백업 버킷 권한은 AI 함수에 일절 없음.

**이전으로 해소되는 현행 약점** — 지금 파이프라인은 **정적 AWS 키**로 Bedrock 을 호출하고 있고 루트에 평문 키 CSV 도 존재합니다. 이전 후에는 Lambda 실행 역할이 이를 대체해 **장기 자격증명이 소멸**합니다 — 별도 조치 요청이 아니라 이번 설계의 효과입니다. 마무리 절차: 병행 운영 검증 → 키 사용처 0 확인 → 비활성화 7일 관찰 → 삭제(비가역이므로 마지막).

**네트워크 경로** — 전 함수 VPC 밖(D-3 권고 시). 온프렘 PG 접근 경로는 Site-to-Site VPN(리드타임 미확인) vs **이미 가동 중인 Cloudflare Tunnel 활용**(리드타임 0, PG TCP 구성 가능 여부 검증 필요) 2후보 — 착수 주에 Tunnel 부터 검증합니다.

## 5. 비용 (월, MAU 500)

현재 기준선 4,577원은 **LLM 토큰 계산치**(크레딧 부담 247원 병기)이지 청구액이 아닙니다 — 이전 후에도 같은 정의로 비교합니다. 단가에 리전 미명시 자료가 섞여 있어(§7) 배수는 **하한선**입니다.

| 항목 | 금액 | 기준선 대비 |
|---|---|---|
| LLM 토큰 (모델 유지 시) | 4,577원 | 1.0배 (불변) |
| Lambda 컴퓨트 | ≈ ₩700 [추정: 월 6만 호출×1s×0.5GB] | +0.15배 |
| SQS·DynamoDB·CloudWatch Logs | 소액 방향 [미확인 — Logs 는 과소평가 주의] | — |
| **NAT 고정비 (VPC 안 선택 시에만)** | **≥ ₩45,300** [리전 미확인·하한] | **≥ 9.9배** |
| **프라이빗 엔드포인트 고정비 (선택 시)** | ≥ ₩10,100 [리전 미확인·하한] | ≥ 2.2배 |
| (변동비 별도) NAT·엔드포인트 데이터 처리 | GB당 과금 [리전 미확인] | 소액 방향 |
| **권고 구성(VPC 밖) 합계** | **≈ 5,300~6,000원 + 미확인 소액** | ≈ 1.2배 |

## 6. 일정 (발표 8/18 고정 가정 — 단, 발표 일시가 문서에 없어 미확정. 확정 시 전면 재계산)

달력: 오늘 8/7(금) → 인계 8/8(토) 16시 → **결정 8/9(일)** → 착수 8/10(월) → 발표 8/18(화). **가용 작업일 = 8/10~8/17, 평일 6일(주말 포함 시 8일).**

작업량 계수(Replatform=2~3일, Refactor=5~10일): 배치 4종 = 8~12, 동기 2종 = 10~20, **합 18~32일분**.

| 안 | 범위 | 계수 vs 가용 | 판정 |
|---|---|---|---|
| 원안 | 6종 전부 완주 | 18~32 vs 6~8 | **불가능** — 산술적으로 닿지 않음 |
| **축소 (권고)** | 요약·감정 확정 완주 + NER·가격(선행 조건 — 아티팩트·Kafka 경로 — 충족 시) + 영수증 착수(8/14 게이트에서 미완 시 발표 범위 제외) | 8~12(+영수증 5~10) vs 6~8 | 요약·감정은 확실, NER·가격·영수증은 조건부 — 미충족분은 자동 이월 |
| 최소 | 요약·감정 2종 + 발표 정정(D-4)만 | 4~6 vs 6~8 | 여유 — 검증·리허설에 잔여 투입 |

D-1 이 8/9 를 넘기면 축소안의 "영수증 착수"가 소멸합니다. **배치 4종은 D-1 과 무관하게 8/10 착수 가능**합니다(요약·감정의 모델 ID 는 파라미터라 B 선택 시 재실측만 추가, NER·가격은 LLM 미사용). 단 **D-6 의 답이 '가'(EKS 선행)이면 착수 순서 전체가 재편**됩니다.
