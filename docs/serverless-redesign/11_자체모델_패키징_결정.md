### 1-3. 가격 이상 탐지 (z-score) — 아티팩트 없음, 패키징 쟁점 없음 (판정 확정)

**판정: 순수 계산 — "아티팩트 없음 — 모델 패키징 쟁점 없음".**
- 모델 파일·학습 단계가 존재하지 않는다. 매 실행 PG `retail_price×retail_product` 를 KST 영업일 단위로 재집계(윈도우 상한 30일·최소 표본 7)해 (품목,소스)별 μ·σ 를 그 자리에서 계산한다 [출처: pipelines/ingest/detect_price_anomaly.py:39-46·70-108·140-178, 조회 2026-08-09].
- 수치 계산은 **stdlib `statistics`**(mean·pstdev)뿐 — numpy·scipy·sklearn import 0건 [실측 — import 목록: argparse·json·statistics·dataclasses·datetime·pathlib + `_db`]. 네이티브 확장 필요 없음.
- "모델 상태"에 해당하는 것은 전부 **PG 테이블**이다: `price_baseline`(μ·σ·표본수 upsert — 오탐 게이트의 데이터 근거)·`price_anomaly`(탐지 기록·`ON CONFLICT` 멱등·`published_at`) [출처: detect_price_anomaly.py:189-209·251-256]. 7일 쿨다운은 fan-out 컨슈머 측(계약표 멱등성 셀과 일치).
- **단, 함수 zip 의 쟁점은 남는다(모델이 아니라 코드 의존성)**: `--emit` 경로가 `pipelines/stream/produce_price_anomaly.emit_anomalies` 를 import 하고 [출처: detect_price_anomaly.py:329-342], stream 의존성 = `confluent-kafka>=2.5` [출처: pipelines/stream/requirements.txt] — **librdkafka C 확장**. 이는 2단계에서 "네이티브 확장 호환성(zip vs 컨테이너)" 축으로 평가하되, 모델 패키징 4방식(A~D)의 대상은 아니다.

**로딩·호출·스키마(참고 기록).**
- 로딩: 해당 없음(무상태). 호출 = CronJob 매일 04:40 KST [출처: FACTS/02_as_built.md §1 배치 행·§2 #6] → 서버리스 계약 `mp-ai-price-detect`(cron UTC 19:40) [출처: 10_구현_인계_계약.md §2].
- 입력: 없음(전 구간 재계산) + argparse `--window/--z/--min-drop/--min-samples/--top-n/--json/--emit/--persist/--mature-samples/--allow-immature`(기본 dry-run — `--emit` 없이 발행 안 함, `--emit`은 `--persist` 함의) [출처: detect_price_anomaly.py:259-279]. 라이브 CronJob 이 어떤 플래그로 도는지는 [미확인 — 확정 방법: mealplanning-config 레포의 해당 CronJob args 확인].
- 출력: stdout 요약 + (옵션) JSON + PG 2테이블 upsert + Kafka `price.anomaly.detected`(payload = Anomaly dataclass asdict + `db_id`, 전량 전달 확인 후에만 `published_at` 갱신) [출처: detect_price_anomaly.py:111-128·305-348].

### 1-4. 인벤토리가 2단계에 넘기는 쟁점 (예고 — 판단은 2·3단계에서)

1. **CRF**: 유일 쟁점은 크기(343,657 B ≈ 0.34 MB)가 아니라 **①단일 사본 리스크(확보 선행)**와 **②pycrfsuite 네이티브 확장의 zip 성립 여부**. 4방식 비교는 이 두 축이 지배한다.
2. **LightGBM**: 방식 비교 전에 **아티팩트 실존 확인이 선행**(존재하지 않으면 "켤 경우" 갈래는 재학습 데이터 트랙까지 소급된다). flag OFF 이므로 "안 켤 경우" 갈래는 패키징 결정 자체가 불요.
3. **z-score**: 4방식 비교 대상에서 **제외 확정**. price-detect 함수의 zip 쟁점은 confluent-kafka 하나로 좁혀진다.
