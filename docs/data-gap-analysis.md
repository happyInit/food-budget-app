## 1. 한 줄 요약

**인프라는 대용량·실시간·이벤트드리븐(Kafka/KEDA/fan-out)을 전제하는데, 그걸 먹일 데이터가 없다.**
소매 크롤링 소스가 전멸(🔴 4/6)하고 회색 단일 소스(마켓컬리)만 남으면서, 서비스 비전이 *"다매장 최저가 + 실시간 시세"*에서 *"단일 채널 현재가 조회(저장 X)"*로 **조용히 축소**됐다. 유일했던 실시간 데이터(도매 경락가)는 **페르소나 부적합**이라는 이유로 제거됐고, 그 자리를 메울 *"소매-관련 + 합법 + 대용량/실시간"* 소스가 아직 없다.

## 3. 확인된 갭 3가지

**① 대용량 데이터 없음.** 합법 대용량 소스는 식약처(30만종) 하나인데 **정적 영양 CSV**. 가격은 마켓컬리 핵심 SKU 수백 개가 전부. `design.md §8.3`이 스스로 *"수십만 행·수백 MB → 단일 PG 충분, ClickHouse 불필요"*로 대용량을 부정.

**② 실시간 데이터 없음.** 마켓컬리 폴링 = 일 1~2회. 유일한 실시간 축이던 지마켓 타임딜은 🔴, 도매 경락가는 제거됨(§5). 최저가 이상탐지는 수 주치 baseline 필요하나 수백 SKU 일배치로는 학습셋이 거의 안 쌓임(`§4.1` "baseline 4주→오탐↑" 자경고).

**③ NER moat 학습 상류 봉쇄.** CRF NER의 주 학습 소스 만개(ai-train=no)·냉부(정형 부재)가 둘 다 🔴. `CLAUDE.md`가 미완으로 둔 "AI 학습 목적 TDM 법률검토"도 선행 필요.

## 4. 두 개의 미스매치 — "틀어짐"의 정체

**(A) 인프라 야심 ↔ 데이터 현실.** 인프라는 Kafka(Strimzi)·KEDA·HPA·최저가 fan-out·피크 스파이크를 전제한다. 그런데 이를 먹일 대용량·실시간 데이터가 없다. `data-validation §4` 경고 그대로: *"DAU·fan-out 추정 이전에 '그 트래픽이 소비할 가격 데이터가 파이프라인에 유입되는가'가 먼저 깨진다."* → 설계 갭이자 **캡스톤 데모 신뢰성 리스크**(스트리밍 인프라인데 흐를 것이 없음).

**(B) 서비스 비전의 조용한 축소.** 원래 *"다매장 최저가 비교 + 실시간 시세"* → 현 스펙(`service-spec-handoff.md §4`) *"⚠️ 다매장 비교 아님, 현재가만, 정보만 제공(저장 X)"*. 가격 이력·시세·저점 알림·할인 예측 전부 드롭/보류. → 사용자가 체감한 "생각과 틀어짐"의 실체.

## 5. 핵심 딜레마 — 소매 관련성 vs 데이터 확보 가능성

> **왜 실시간 데이터가 사라졌나:** 도매 경락가가 사실상 **유일한 실시간 데이터**였으나, *"도매가는 20-30대 1인 가구 체감가와 무관"*이라는 멘토 지적으로 제거됐다. 이 지적 자체는 타당하다(1인가구는 도매시장에서 사지 않는다). 문제는 **그 자리를 메울 '소매-관련 + 합법 + 대용량/실시간' 소스가 없다는 것.**

| 축 | 실시간 | 대용량 | 합법 | 페르소나(소매) 관련성 |
|---|---|---|---|---|
| 도매/경락가 (KAMIS 도매·경락) | ✅ | ✅ | ✅ | ❌ 도매 ≠ 1인가구 체감가 |
| 소매 크롤 (쿠팡·지마켓) | ~✅ | ✅ | ❌ 차단 | ✅ |
| 마켓컬리 사설 API | ❌ 일배치 | △ 수백 SKU | △ 회색 | △ 프리미엄 편향 |
| 유저 영수증 크라우드소싱 | ❌ | ❌ 초기 희박 | ✅ 본인데이터 | ✅ 실구매가 |

**→ 미해결 핵심 질문: "소매-관련 가격을 합법·대용량·실시간으로 어떻게 얻는가."** 네 축 어느 하나도 4개 요건을 동시에 못 채운다.

## 6. 돌파구 후보 (팀 결정 대기 — 임의 확정 금지)

| 방향 | 내용 | 얻는 것 | 트레이드오프 |
|---|---|---|---|
| **A. 공공 가격 오픈데이터 재도입** | 드롭한 KAMIS 등 재검토. 축을 "리테일 최저가 비교"→**"시세 인텔리전스 + 예산"**으로 조정 | 합법·대용량·실시간에 가장 근접, 인프라 서사와 정합 | 도소매 시세 ≠ 장바구니 실구매가(층위 차이) |
| **B. 유저 크라우드소싱 가격** + 마켓컬리 병행 | `§8.5` 권장. 지속가능 실구매 baseline | 합법·실구매가·콜드스타트 부트스트랩 | 초기 희박, HITL |
| **C. 현실에 맞춰 정직 축소** | 현 방향(마켓컬리 단일 정보 제공) 고수 | 리스크 최소·빠름 | 대용량/실시간/인프라 서사 포기(사용자 불만 방향) |

**재검토 가치 있는 가설 (research 필요, 확정 아님):**
- **공공 가격 오픈데이터는 도매뿐 아니라 소비자(소매)가격도 제공할 수 있다.** 멘토 지적("도매가 무관")이 *도매 경매가*엔 맞아도 *공공 소비자가격 통계*까지 배제하는지는 **재검증 필요**. 이게 참이면 A의 페르소나 트레이드오프가 상당 부분 해소.
- **도매→소매 보정 모델**: 도매 시세를 "방향성 시그널"로 쓰고 실구매가는 크라우드소싱으로 확정하는 하이브리드.
- **NER 상류 대안**: 공공 레시피 오픈데이터 재검토 / YouTube·영수증 기반 자체 약라벨 부트스트랩.

⚠️ 어떤 방향이든 **anti-bot 우회를 전제한 계획은 금지**(학생예산·비상업 하드제약).

## 7. 팀 회의 안건 (미해결 결정)

1. **소매-관련 가격을 합법·대용량·실시간으로 어떻게 확보할 것인가** (§5 딜레마의 정면 돌파).
2. **인프라 서사를 데이터에 맞출 것인가, 데이터를 인프라에 맞출 것인가** (§4-A 미스매치 해소 방향).
3. **축을 "시세 인텔리전스"로 넓힐 것인가, "예산 트래커"로 좁힐 것인가** (§4-B 비전 재확정).
4. NER moat 학습 코퍼스 합법 대안 + TDM 법률검토 완료.
