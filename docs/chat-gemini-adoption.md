## 0. 한 줄 요약

Gemini Flash-Lite를 **응답 다듬기(refine-only) 층**으로만 붙이고, 검색·근거조립·거절판정은 기존 TemplateGenerator가 그대로 담당한다. 실측 결과 **신규 레시피 추천 1건당 ~0.06원**, 오프토픽·가격·영양·반복질문은 **0원**. 월 지출 상한 8,000원은 현실 예상 사용량의 **14~28배 여유**이자 폭주 방지 하드캡으로, 비용 부담이 실질적으로 없다.

---

## 1. 배경 — 왜 붙였나

설계 원안(`chat-assistant-ai.md §2`)은 "DB 병렬조회 → 컨텍스트 조립 → **LLM이 응답을 다듬는다**"였다. 1차 출시는 무료·무승인의 TemplateGenerator로 확정했지만, 템플릿 출력은 검색 결과를 기계적으로 나열하는 수준이라 자연스러움이 떨어진다. 그 "다듬기 층"을 원안대로 실제로 붙여 품질 향상폭과 비용을 실측하는 것이 이 작업의 목적이다.

**핵심 설계 결정 — Gemini는 "다듬기"만, "생성"이 아니다:**

```
추출 → DB 병렬검색 → 컨텍스트 조립 → TemplateGenerator(근거 조립 + 거절 판정)  → Gemini 다듬기
                                                       └ 거절/skip이면 여기서 종료(호출 안 함)
```

- Gemini는 raw DB를 보지 않는다. TemplateGenerator가 만든 **근거 텍스트만** 자연스럽게 재작성한다 → 환각(없는 레시피·가격 지어내기) 원천 차단.
- 거절("모르겠어요")·95% 관련성 게이트는 TemplateGenerator에 있으므로 백엔드를 바꿔도 **정답률이 동일**하다(검증: `VALIDATION_LOG.md` iter5 = iter4와 동일 27/27).

## 2. 무료 티어 시도와 한계 (실측)

먼저 개인 무료 티어 키로 시도했고, 다음과 같이 **무료로는 안정적 사용이 불가**함을 확인했다.

| 모델 | 무료 티어 결과 |
|---|---|
| `gemini-2.5-flash-lite` | **404 NOT_FOUND** — "no longer available to new users" (신규 계정에 미개방) |
| `gemini-2.0-flash-lite` | **429 RESOURCE_EXHAUSTED** — 무료 쿼터 소진 |
| `gemini-flash-lite-latest` (별칭) | 호출은 되나 무료 쿼터·RPM 제한에 걸림 |

무료 티어는 분당 요청수(RPM)·일일 요청수(RPD) 제한이 빡빡해, 피크타임(11-12·17-18시) 트래픽이나 검증 스위트(연속 호출)조차 429로 막힌다. 즉 **데모·실측 용도로도 부적합**.

---

## 3. 유료 전환과 효과

유료 계정 전환 후:

| 항목 | 효과 |
|---|---|
| 모델 접근 | `gemini-flash-lite-latest`(별칭=항상 최신 최저가 lite) 안정 사용 — 버전 deprecated 회피 |
| 쿼터 | 429 RESOURCE_EXHAUSTED 해소 — 연속 호출·검증 스위트 정상 |
| 품질 | 템플릿 나열 → 자연스러운 문장. 예: "두부랑 대파" 질문에서 템플릿은 대파 레시피만 나열했으나 Gemini는 *"두부 활용 요리가 없어서 대파 기반으로 추천"*이라고 **매칭 상황까지 정직하게 설명** |
| 근거보존 | 레시피명을 근거 그대로 사용, 근거 밖 숫자 생성 시 `check_output_grounded`가 잡아 template로 fallback (유닛+라이브 확인) |

프리페이드 **16,000원 충전 + 월 지출 상한 8,000원** 설정 = 자동 재충전 서프라이즈 없음 + 월 상한 하드캡.

## 4. 비용 구조 (실측 기반)

### 4.1 호출당 토큰 (실측)

refine-only라 프롬프트가 작다. 실제 호출 usage_metadata 평균:

| 구분 | 토큰 | 비고 |
|---|---|---|
| 입력 | **~174** | 시스템 지시(~120) + 질문(~20) + 근거 텍스트(~35) |
| 출력 | **~71** | 2~4문장 (상한 200토큰) |

> 참고: `chat-assistant-ai.md §4`의 초기 추정(입력 ~2,000토큰)은 풀 RAG 프롬프트 가정이었다. 실제 refine-only 부하는 **그 1/10 수준**이다.

### 4.2 호출당 비용

Flash-Lite 요율(입력 $0.10 / 출력 $0.40 per 1M tokens 기준, 시점별 변동 — 현재가 확인 권장):

| 항목 | 계산 | 비용 |
|---|---|---|
| 입력 | 174 × $0.10/1M | $0.0000174 |
| 출력 | 71 × $0.40/1M | $0.0000284 |
| **합계/호출** | | **$0.000046 ≈ 0.06원** (₩1,380/$ 기준) |

## 5. 비용 최소화 설계 — 실제 과금 호출을 최소화

호출당 단가(0.06원)도 작지만, **호출 자체가 발생하는 경우를 3개 레버로 줄였다.**

| 레버 | 내용 | 효과 |
|---|---|---|
| ① 거절 skip | 오프토픽·무근거 질문은 template floor가 거절 → Gemini 호출 안 함 | 오프토픽 **0원** |
| ② 선택적 다듬기 | 가격·영양은 이미 깔끔한 구조화 사실 → 다듬기 skip, **레시피 추천만** 호출 | 조회형 질문 **0원** |
| ③ Redis 캐시(30일) | 동일 근거(grounded_text) 재질문은 캐시 반환 | 반복 질문 **0원** |

추가로 max_output_tokens 200 상한, temperature 0.3(환각 억제), 타임아웃 8초 fallback.

**→ 실효 과금 대상 = "처음 나오는 레시피 추천 질문"뿐.** 그 외 전부 0원.

## 6. 월 상한 8,000원의 타당성

### 6.1 상한이 커버하는 호출 수

`8,000원 ÷ 0.06원/호출 ≈ 약 127,000 신규 추천 응답/월`

### 6.2 현실 예상 사용량 (여유 확인)

`design.md`의 가정(DAU 500)에 어시스턴트(P1) 사용률을 보수적으로 얹어 추정:

| 시나리오 | 신규 추천 호출/월 | 예상 비용/월 |
|---|---|---|
| 초기 실험(소수 유저·데모) | 수천 건 | 수백 원 |
| DAU 500 × 어시스턴트 사용 20% × 3회/일 × 캐시 50% | ~4,500 건 | **~285원** |
| 위와 동일, 캐시 0% (최악) | ~9,000 건 | **~570원** |

→ 현실 예상(월 300~600원)의 **14~28배** 지점에 8,000원 상한이 있다. 정상 운영에선 절대 닿지 않는다.

### 6.3 상한의 이중 역할

1. **여유 헤드룸** — 트래픽이 예상보다 크게 늘어도 버틴다.
2. **폭주 방지 하드캡** — 코드 버그(무한 재시도)·남용(자동 스팸 호출) 시 8,000원에서 API가 멈춰 **서프라이즈 청구를 원천 차단**. 프리페이드 16,000원(= 상한 2개월치 버퍼)과 함께 재정 리스크를 상한선으로 못박는다.

---

## 6.4 비용 외 트레이드오프 — 지연시간 (실측)

비용과 별개로 Gemini는 **응답 지연**을 더한다(실측, `services/chat/validation/GEMINI_IMPACT.md`):

| 응답 유형 | template | gemini |
|---|---|---|
| 레시피 추천 | ~수십 ms | **~0.8~1.3초** (LLM 왕복) |
| 가격·영양·거절 | ~수십 ms | ~수십 ms (호출 안 함, 동일) |

추천 응답에만 ~1초가 붙는다. 대외 시연의 자연스러움과 맞바꾸는 것이며, 완화책은 캐시
히트(반복질문 즉시)·향후 스트리밍 응답. 조회·거절·반복질문은 영향 없다.

## 7. "비용 부담이 크지 않다"의 근거 정리

- **단가가 작다**: 다듬기 전용 설계로 호출당 ~0.06원 (풀 RAG 대비 1/10 프롬프트).
- **호출 수가 작다**: 거절·가격·영양·반복질문은 0원, 신규 추천만 과금.
- **예상 지출이 상한보다 훨씬 작다**: 현실 시나리오 월 300~600원 vs 상한 8,000원.
- **상한이 최악을 막는다**: 버그·남용도 월 8,000원에서 강제 정지.
- **향후 0에 수렴**: AWS 크레딧 확보 후 Bedrock(Nova Lite/Claude Haiku)로 이전하면(`chat-assistant-ai.md §3`) 크레딧으로 충당돼 실지출은 사실상 0. `Generator` 인터페이스라 백엔드 교체는 코드 한 줄. *(주의: Bedrock에는 Gemini가 없다 — 이전 시 Nova/Claude로 모델이 바뀐다.)*
