# mp-ai-rank-serve — **컨테이너 이미지용**. 다른 10종과 달리 **락 파일이 아니라 범위 핀**이다.
#
# 🔵 왜 락이 아닌가 = zip 함수들은 호스트에서 `pip download --platform` 으로 받는데,
#    `--platform`·`--python-version` 은 **휠 선택에만** 영향을 주고 **환경 마커는 빌드
#    기계의 인터프리터로 평가**된다. 그래서 전이 의존까지 손으로 박아야 재현이 됐다.
#    여기는 **목표 이미지 안에서** 설치하므로 마커가 목표 환경으로 평가된다 — 그 함정이 없다.
#
# 정본은 `ml/recipe-ranking/requirements.txt` 다. 아래는 거기서 **서빙에 필요한 것만** 남긴 것:
#
# 🔵 뺀 것
#   · `uvicorn`      — 서버가 필요 없다. Mangum 이 ASGI 앱을 직접 호출한다.
#   · `python-dotenv`— `.env` 파일을 읽을 일이 없다(설정은 Lambda 환경변수).
#   ⚠️ `scikit-learn` 은 **못 뺀다** — lightgbm 이 있어도 모델이 폴백(GradientBoosting)으로
#      학습됐으면 언피클에 sklearn 이 필요하다. 어느 학습기로 구운 모델인지는 `ranker.pkl`
#      쪽 사정이라, 서빙이 그걸 전제하면 «가끔 죽는 배포» 가 된다.
#
# 🔴 `lightgbm` 은 파이썬 휠만으로 부족하다 — `libgomp` 를 Dockerfile 이 깐다.
