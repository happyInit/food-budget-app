# 이 함수가 실제로 쓰는 레포 모듈만 적는다(build.sh 가 이 목록만 번들에 넣는다)
#
# 🔵 **디렉터리 한 줄**이다 — ocr 앱이 패키지 구조(`app/pipeline/backend/...` 3단)라
#    평면으로 풀면 `from app.pipeline.backend.factory import ...` 가 전부 깨진다.
#    build.sh 가 basename 그대로 번들 루트에 넣어 `app/` 이 선다(chat 과 같은 방식).
#
# 🔴 **디렉터리를 담으면 «명시적으로 고른다» 는 성질이 약해진다.** 안에 뭐가 딸려오는지
#    직접 확인했다(2026-08-17):
#      · `app/static/demo.html` — 데모 UI. 워커는 안 쓰지만 20KB 라 걷어낼 값이 없다.
#      · `app/config_canary.py` — PIL 을 **함수 안에서** 지연 import 한다(최상단 아님) → 무해.
#    심볼릭 링크는 **없다**(chat 과 달리 ocr 은 vendor 링크가 없다 — 확인함).
#
# 🔴 아래 `-` 두 줄 = **담았다가 도로 빼는 것.** 워커는 HTTP 를 안 받으므로 이 둘을 쓰지 않는데,
#    `app/main.py` 가 최상단에서 `fastapi` 와 `prometheus_fastapi_instrumentator` 를 import 한다.
#    남겨 두면 «번들에 없는 의존성» 으로 검사에 걸리고, 그걸 달래려다 **쓰지도 않는 패키지
#    5MB 를 번들에 넣게** 된다. 빼는 편이 정직하다 — 실수로 import 하면 즉시 터진다.
#    `app/store.py` 도 같이 뺀다: 잡 상태는 `common/jobs.py` 가 **같은 키**(`ocr:job:{}`)로 쓴다.
#
# 🔵 gazetteer·소비기한 사전은 **PG 에서 읽는다.** `classify.py` 가 CSV 폴백 경로를 갖고 있지만
#    그 경로(`parents[4]`)는 번들 깊이에서 성립하지 않아 파일이 없고, 그러면 DB 갈래로 떨어진다
#    — **컨테이너에서 도는 방식과 같다**(Dockerfile 도 `app/` 만 COPY 한다). 그래서 CSV 를
#    번들에 넣지 않는다. 넣으면 오히려 파드와 다른 사전을 쓰게 된다.
